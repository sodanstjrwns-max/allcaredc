A LETTER TO YOU

원장님, 늦은 밤 죄송합니다. ㅎㅎ
홈페이지가 완성이 되어 전달드리지 아니할 수가 없었습니다.

정말 하얗게 불태웠습니다. 병원의 미래 성장을 바꿀 홈페이지의 탄생이라고 자신합니다.

이 홈페이지는 세 가지를 담고 있습니다.
  1. SEO — 검색엔진 크롤러들이 긁어가도록
  2. AEO — AI 크롤러들이 긁어가도록
  3. 체류시간 — 사람이 실제로 보고 내원을 결정할 수 있도록

따라서 이 홈페이지는 기능적으로 로봇이 좋아할 만한 많은 특성을 담고 있습니다. 예를 들어 각 진료 페이지의 내용을 아주 상세하게 써놓은 부분이나, 존재하는 수많은 페이지들은 사실 사람이 다 읽길 기대하는 콘텐츠라기보단 크롤러가 긁어가고 추천하기 좋게 만든 용도입니다.

그에 더해, 이 홈페이지는 앞으로 가만히 내버려두면 안 됩니다. 계속 케이스도 올려주시고 블로그 포스팅도 올려주시면, 앞으로 돈값 ×100 이상은 할 수 있는 홈페이지라고 말씀드릴 수 있습니다. 하나하나의 케이스와 포스팅이 매번 새로운 검색어로 우리 홈페이지에 유입을 만들어낼 것입니다.

이 홈페이지를 만드신 목적을 절대 잊으시면 안 됩니다.

일단 밤이 늦었으니 편히 보시고, 어떤 방식의 피드백도 환영합니다.

— 문석준 드림
THE CORE · 최대 의의

이 홈페이지의 심장 — SEO · AEO

사람에게 예쁜 홈페이지는 많습니다. 이 홈페이지의 최대 의의는 ‘검색되고, AI에게 추천받는’ 데 있습니다.

1 SEO — 검색엔진이 긁어가도록

네이버·구글·빙이 우리 페이지를 정확히 이해하고 상위에 올리도록 설계했습니다.

  • 모든 페이지에 고유한 제목·설명·대표주소(canonical) 적용
  • 진료시간·위치·전화·의료진·진료항목·FAQ를 검색엔진이 바로 읽는 구조화 데이터(Schema)로 심음 → 검색결과에 진료시간·지도가 풍부하게 노출될 토대
  • 진료 페이지의 압도적 상세함 — 사람이 다 읽기 위한 게 아니라, 크롤러가 긁어가 ‘이 병원은 이 분야 전문’이라고 판단하게 만든 장치
  • 자동 색인 통보(IndexNow) — 새 글 올리면 검색엔진에 ‘새 글 나왔다’ 즉시 통보

2 AEO — AI가 긁어가고 추천하도록

이제 환자는 “약수역 임플란트 잘하는 곳”을 챗GPT에게도 묻습니다. 그 답에 우리가 나오도록 만들었습니다.

  • ChatGPT(GPTBot)·Claude·Perplexity 등 AI 검색봇을 명시적으로 환영하도록 설정
  • AI가 읽기 좋은 전용 지식파일(llms.txt, ai.txt)까지 별도 제작
  • 음성검색·AI 스피커 대응(Speakable 데이터) → ‘AI에게 추천받는 치과’의 기반

3 체류시간 — 사람이 보고 내원을 결정하도록

로봇만을 위한 게 아닙니다. 들어온 사람이 머물고 신뢰하게 만들었습니다.

  • 환자의 심리 흐름을 따라가는 콘텐츠 배열 (인지 → 신뢰 → 결심 → 예약)
  • 전문의 직접 진료 강조 → 사례·후기 → 오시는 길 → 예약으로 자연스럽게 흐르는 동선
  • 읽다 보면 ‘여기 가봐야겠다’로 이어지도록 설계

ADMIN GUIDE

관리자 페이지 사용법

원장님이 직접 케이스·포스팅을 올리실 수 있도록 정리했습니다. 이게 돈값 ×100의 열쇠입니다.

들어가는 방법

  • 브라우저에서 https://allcaredc.kr/admin 접속
  • 비밀번호 입력 → 로그인
⚠️ 보안 — 관리자 비밀번호 변경
현재 관리자 비밀번호가 초기 비밀번호 allcare2026 으로 설정돼 있습니다. 반드시 변경하셔야 합니다. 원하시는 비밀번호를 알려주시면 안전하게 세팅해 드리겠습니다.

관리자에서 할 수 있는 것

  • 📊 대시보드 — 전체 현황 한눈에
  • 📅 예약 관리 — 홈페이지로 들어온 예약 문의 확인 / 상태변경 / 삭제
  • 👥 회원 관리 — 가입 환자 조회
  • 🖼️ 비포&애프터(치료사례) — 가장 중요! 새로 등록·삭제
  • ✍️ 컬럼(칼럼) 포스팅 — 작성·수정·삭제 (SEO 최적화 글쓰기)
  • 📢 공지사항 — 작성·수정·삭제, 팝업 띄우기
  • 🎉 이벤트 — 작성·수정·삭제
📌 비포&애프터 올리는 법
관리자 → 비포&애프터 → 새 사례 등록 → 제목·설명·연령대·성별·진료종류·지역·담당의·치료기간 입력 + 사진 업로드(파노라마 전/후, 구강내 전/후) → 저장
→ 저장 즉시 검색엔진에 자동 통보됩니다.
📌 블로그 포스팅(컬럼) 쓰는 법
관리자 → 컬럼 → 새 글 작성 → 제목·본문·요약·작성자·카테고리·썸네일 입력
→ 고급(SEO): 검색용 제목·검색용 설명·키워드·FAQ를 채우면 검색 노출이 훨씬 강해집니다.
→ ‘발행’에 체크하고 저장해야 공개됩니다. (체크 안 하면 임시저장) → 발행 시 검색엔진 자동 통보.
📌 공지·팝업 띄우는 법
관리자 → 공지사항 → 새 공지 작성 → 제목·내용·이미지 입력
  • 상단 고정 체크 → 공지 목록 맨 위 고정
  • 팝업 체크 → 홈 접속 시 팝업으로 노출
  • 팝업 종료일 설정 → 그 날짜까지만 자동 노출
IMPORTANT

가장 중요한 당부 — “심어야 거둡니다”

새 홈페이지가 검색엔진에 풍부하게 색인되기까지는 시간이 필요합니다.

⏳ 예상 소요 기간
빠르면 약 2개월, 늦으면 6개월 정도 걸릴 수 있습니다. (홈페이지마다 편차 있음)
검색엔진이 신규 사이트를 신뢰하고 상위에 올리는 데에는 절대적인 시간과 ‘꾸준한 콘텐츠 축적’이 필요하기 때문입니다.

✅ 그래서 가장 중요한 것은, 이 색인 기간 안에 케이스와 포스팅을 최대한 많이 쌓아두시는 것입니다.

  • 사례·글이 많을수록 → 색인되는 페이지가 많아지고 → 매번 새로운 검색어로 유입이 생깁니다.
  • 처음 몇 달의 꾸준함이 1년 뒤 광고비 없이 들어오는 환자 수를 결정합니다.
한 줄 요약: “지금 심으면 6개월 뒤 수확합니다. 오늘부터 케이스 하나, 포스팅 한 편씩 — 이게 돈값 ×100의 비밀입니다.”
